# Geometric ox concept

Generated with the built-in image-generation tool, then reconstructed as deterministic SVG geometry for the application. The bitmap is exploratory reference only.

Prompt: Create a refined identity for oxAudit, a local-first engineering security audit desktop workbench for code, dependencies and binary inspection. One square app icon: an elegant, restrained geometric ox-head symbol with bracket-like upward horns and a compact central face, crisp negative space, 2–3 broad solid shapes legible at 24px. Symmetric, confident and calm; no swords, shield, padlock, eyes, tiny circuitry, letters or text. Warm pale gold #C8B560 on a dark graphite #151719 rounded-square tile with transparent outer margins. Production identity quality and precise spacing. Reconstruct as a clean repo-native SVG master for favicon, React mark and native app icons.

Production adaptation: flattened the generated lighting, simplified the contours, made the horns exactly symmetric and retained the existing theme-aware UI color. Source: src/components/brand/geometry.ts.
