# oxAudit v0.3.2

A packaging release. The code is the same as v0.3.1; the Linux binaries are
built differently. See the [changelog](../../CHANGELOG.md#032---2026-11-17),
and the [v0.3.1 notes](v0.3.1.md) for everything new in the 0.3 line.

## What changed

- **Linux binaries run on older systems.** The Linux x86_64 and aarch64
  CLIs and the Linux desktop packages are built on Ubuntu 22.04 and need
  glibc 2.34, so they run on Ubuntu 22.04, Debian 12 and RHEL 9. v0.3.1's
  needed glibc 2.39 and failed to start there with a `GLIBC_2.39 not found`
  error.
- The release workflow checks the glibc version each Linux binary needs and
  fails if it is newer than 2.34.

## Upgrade notes

- Pipelines pinned to v0.3.1 that run on Ubuntu 24.04 need no change. To run
  on Debian 12, Ubuntu 22.04 or RHEL 9, move the version and the SHA-256 pin
  to v0.3.2 together.
- This release has no container image and no minisign signatures, as its
  release page states: the registry refused the image push, and the
  repository holds no minisign key.
