# oxAudit v0.3.3

A rebuild with no code changes. See the
[changelog](../../CHANGELOG.md#033---2026-11-17), and the
[v0.3.1 notes](v0.3.1.md) for everything new in the 0.3 line.

## Why this release exists

v0.3.1 and v0.3.2 shipped without a container image: the registry refused
pushes from the release workflow. The registry's access for this repository
has since been corrected, and this release has the image again. Its
reference pinned by digest is in the release asset `oxaudit-container.txt`:
`ghcr.io/henrycooper86/oxaudit@sha256:1825a8b82c7369ff98786e286e6910a7303eb02274cbffb149ed0ae13b0ffb54`.
It carries `oxaudit-cli` and the headless server for linux/amd64 and
linux/arm64; see the [server guide](../headless-server.md#container).

## Unchanged from v0.3.2

- The Linux CLIs and desktop packages need glibc 2.34 and run on Debian 12,
  Ubuntu 22.04 and RHEL 9.
- No minisign signatures: the repository holds no minisign key. Verify with
  `gh attestation verify` or `cosign verify-blob`.
